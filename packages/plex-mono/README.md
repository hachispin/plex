# IBM Plex Mono

Desktop TrueType fonts are in [fonts/complete/ttf](fonts/complete/ttf/). Open the `.ttf` files in your desktop font manager to install them.

Includes all eight weights, in upright and italic styles. Italics use the single-storey `g` and its accented forms by default.
